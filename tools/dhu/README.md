# Desktop Head Unit

Test the Android Auto screen on a computer without a car.

1. Install the Desktop Head Unit from the Android SDK Manager (SDK Tools > Android Auto Desktop Head Unit Emulator).
2. On the phone: Android Auto > tap the version 10 times > Developer settings > Start head unit server.
3. Connect the phone over USB and run `dhu.bat` (Windows) from this folder.

`small_head_unit.ini` emulates an 800x480 touch screen, a common size for factory head units.
